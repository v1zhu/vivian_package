# Installation

## Stable release

To install vivian_package, run this command in your terminal:

```
pip install vivian_package
```

This is the preferred method to install vivian_package, as it will always install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this [Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) can guide you through the process.

## From sources

To install vivian_package from sources, run this command in your terminal:

```
pip install git+https://github.com/v1zhu/vivian_package
```
